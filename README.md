# VENT Zibo Fleet DOW Manager

A Lua-based DOW Manager for the Zibo 737 in X-Plane 12.

## Version

**v3.7**

## Installation

1. Extract the ZIP archive.
2. Copy the included files to your X-Plane 12 `Resources/plugins/FlyWithLua/Scripts` folder.
3. Start X-Plane 12 with the Zibo 737.

## Usage

1. Select the aircraft registration.
2. Select the required DOW option.
3. The manager will automatically adjust the Zibo tablet values to match the selected DOW.

The manager is designed to work with the Zibo 737 and will not run on other aircraft.

## Download

Download the latest version from the repository files.

## Requirements

* X-Plane 12
* Zibo 737
* FlyWithLua
